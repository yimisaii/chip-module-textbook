# 资料检索与 RAG

本包把工作方法放在 `SKILL.md` 和编写参考中，把器件依据放在 `references/platforms/` 的资料卡中。助手检索适用段落后，把来源和段落用于编写，再核对原厂文档。已有资料索引见 [source-catalog.md](source-catalog.md)。

## 当前提供的检索

`scripts/retrieve.py` 使用 Python 3 标准库，读取 Markdown 资料卡，无需数据库、模型 API 或网络服务。从 Skill 根目录运行：

```sh
python -X utf8 scripts/retrieve.py --chip rp2040 --peripheral dma --sdk pico-sdk-2.2.0 "transfer_count 64"
```

默认资料库相对于脚本文件定位，改变工作目录后也可用脚本的实际路径调用。`--library` 指定的相对路径则相对于调用时的工作目录解析。

| 行为 | 实际规则 |
| --- | --- |
| 确定范围 | 只读取 `<资料库>/<chip>/<peripheral>/` 中直接放置的 `.md` 文件 |
| SDK 匹配 | 第一行必须与 `sdk: <请求的版本ID>` 精确一致 |
| 来源 | 第二行必须是非空的 `source: ...` |
| 关键词 | 按空格拆词，忽略大小写，以子串匹配；按段落内匹配到的不同关键词数量排序；匹配任一词即可入选 |
| 输出 | 最多 3 段，各带资料卡相对路径、行号、来源和段落正文 |
| 退出码 | `0` 有结果，`1` 无适用证据，`2` 参数或资料格式错误 |

这是可供助手使用的轻量检索入口。当前没有自动 PDF 入库、OCR、向量嵌入或托管问答服务。没有 Python 或终端时，助手可直接阅读同范围的资料卡和原厂文档。

## 接入自己的教材和 PDF

将持有的原始资料保留在本地或有访问权限的资料源中，记录版本、印刷页/PDF 页、手册小节或源码符号。先从当前样章用得上的小节提炼资料卡。扫描 PDF 需要目视核对或另行 OCR 后校对，尤其关注位宽、下标、单位和代码。

例如，在 Skill 根目录下建立 `private/platforms/rp2040/dma/my-notes.md`。第一、二行是检索元数据，标题及内容从后面开始：

```markdown
sdk: pico-sdk-2.2.0
source: RP2040 Datasheet §2.5 DMA；Pico SDK 2.2.0 hardware/dma.h 的 dma_channel_configure

# 内存搬运的传输计数

本例数据为 64 个 uint32_t 元素，共 256 字节。配置 32 位数据宽度时，传输计数 transfer_count 使用 64 次传输。
```

从 Skill 根目录检索这个私有资料库：

```sh
python -X utf8 scripts/retrieve.py --library private/platforms --chip rp2040 --peripheral dma --sdk pico-sdk-2.2.0 "transfer_count 64"
```

`--library` 选择一个资料库；一次调用不会自动合并默认库和私有库。需要两边资料时分别调用，并保留各自的来源。Skill 根目录的 `private/` 已由本仓库的 `.gitignore` 忽略；资料若放在目标项目的其他目录，应由那个项目单独管理忽略规则。

芯片、外设和 SDK ID 使用小写字母、数字、短横线或点号，例如 `stm32u575`、`gpio-exti`、`hal1-1.6.3`。同一外设目录可以有多个 SDK 的卡片，各卡片使用自己对应的版本行。标题与段落用空行分开。

教学范本可用于借鉴章节组织、插图和习题。寄存器、引脚、电气、时钟和 API 结论由当前芯片资料核对。无命中时补找同器件、同版本证据，并注明待核对项。

## 以后接入本地或云端 RAG

RAG 服务可以运行在本地，也可以运行在云端；本包的 Skill 与 Markdown 资料并不依赖某一种部署。资料量增大、关键词检索难以找到相关段落时，可保留现有资料卡并接入使用者选择的检索系统。

建议为每个分块保留以下信息：

| 字段 | 用途 |
| --- | --- |
| `chip`、`peripheral`、`sdk` | 先筛选适用器件、外设和版本，再做关键词或语义检索 |
| `source`、`locator` | 定位原始 URL、手册版本、小节、印刷页/PDF 页或源码符号 |
| `kind` | 区分原厂事实、教学范本、原创实验、勘误和验证记录 |
| `revision`、`license` | 记录来源修订与可使用/分发范围 |

返回给助手的结果应含原始定位和适用范围。把跨芯片教学范本与当前芯片实现证据分开查询。接入后用 STM32U575 的 256 字节与 RP2040 的 64 次传输做一次单位隔离核验，再用不存在的 SDK 版本检查无证据返回。

这个分块字段表是后续接入约定，现有脚本只读取文件夹范围、`sdk`、`source` 和正文。新增向量库、自动解析或生成服务时，需要另外实现并验证。
